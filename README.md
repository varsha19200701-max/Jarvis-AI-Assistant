# JARVIS AI Assistant — Chat + Voice

A beginner-friendly Python AI assistant with **two ways to interact**:
- **Web chat:** type a message and receive an AI response.
- **Web voice assistant:** record a message using your browser microphone; JARVIS transcribes it, answers, and plays a spoken reply.
- **Conversation context:** recent messages are sent along so JARVIS can follow the conversation.

The AI responses are generated by the Groq API. Voice transcription uses Groq's Whisper transcription API. Spoken replies are generated with gTTS.

> This is a conversational AI assistant. It does not control your computer or perform autonomous background tasks.

## Technologies

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Gradio | Creates the browser-based chat and voice interface |
| Groq API / Groq Python SDK | Generates AI responses |
| Groq Whisper transcription | Converts recorded speech into text |
| gTTS | Creates spoken audio replies |
| python-dotenv | Loads local environment variables |

## Files

- `app.py` — web interface, chat flow, voice transcription, and spoken replies.
- `main.py` — original terminal version with local microphone and speaker support.
- `requirements.txt` — dependencies for the hosted Gradio web app.
- `requirements-local.txt` — dependencies for running the original terminal version locally.
- `.env.example` — example local configuration; never put a real API key in this file.
- `.gitignore` — excludes private/local files.
- `README.md` — project documentation.

## Deploy on Hugging Face Spaces

1. Create or sign in to an account at [Hugging Face](https://huggingface.co/).
2. Create a new Space: [huggingface.co/new-space](https://huggingface.co/new-space).
3. Choose **Gradio** as the SDK and make the Space **Public**.
4. Upload these project files to the Space: `app.py`, `requirements.txt`, and optionally `README.md`.
   You can also connect the Space to this GitHub repository if you prefer.
5. Open the Space's **Settings** page.
6. Under **Variables and secrets**, add a new secret:
   - Name: `GROQ_API_KEY`
   - Value: your newly generated Groq API key
7. Save the secret and wait for the Space to build.
8. Open the running Space. Copy its public URL and replace the placeholder under **Live Demo** above.

**Security:** Add the API key as a Hugging Face Secret. Never paste it into `app.py`, `README.md`, `.env.example`, or a public GitHub file. If a key is exposed, revoke it and create a new one.

## Run the web app locally

Python 3.10 or newer is recommended.

```bash
python -m venv .venv
```

Windows Command Prompt:

```bat
.venv\Scripts\activate
```

Install web-app dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Create a `.env` file by copying `.env.example`, then put your own key in it:

```env
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=openai/gpt-oss-20b
```

Run:

```bash
python app.py
```

Gradio prints a local address, usually `http://127.0.0.1:7860`.

## Run the original terminal version

The original `main.py` uses the computer's local microphone and speakers. Install its separate dependencies:

```bash
pip install -r requirements-local.txt
```

Create `.env` as described above, then run:

```bash
python main.py
```

Choose `1` for Voice Assistant, `2` for Chat Assistant, or `3` to exit.

## How the web app works

1. Gradio displays the chat and microphone controls in a browser.
2. Typed messages go to `get_ai_reply()`.
3. Voice recordings are sent to Groq's transcription endpoint.
4. The recognized words are sent to the same `get_ai_reply()` function.
5. Groq returns an AI answer.
6. gTTS creates an MP3 so the browser can play JARVIS's spoken response.

## Notes

- The hosted app requires internet access and a valid Groq API key stored as a Hugging Face Secret.
- The browser will ask permission to use the microphone.
- Voice transcription and text-to-speech require internet access.
- Free hosting may sleep when inactive; the first visit after inactivity can take time to start.
- Do not commit `.env`, `.venv`, or API keys.
